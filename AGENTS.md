# Repository Rules

## Required start

Before substantive work, read `glutoide/project-memory/AGENTS.md`, then this repository's `PROJECT_HANDOFF.md`.

## Repository status

This repository is a completed public portfolio implementation of Sensorfact's Backend Engineer Technical Assignment. Treat `main` as the accepted baseline unless the owner explicitly requests a new change.

## Rules

- Verify current `main`, Actions, dependency/security advisories and any open PR before claiming current status.
- Preserve the assignment contract and the documented simplified energy model.
- Do not add secrets, credentials, private data or production account material.
- Keep changes proportional to the assignment; avoid unrelated architecture or feature expansion.
- Substantive changes go through a branch, PR and applicable checks.
- Update `PROJECT_HANDOFF.md` only when status, verified results, blockers or the next action materially change.
